## Intel 8048 / 8039 tools

This directory is a reference collection for the Intel MCS-48 family, including the 8039 target architecture and related 8048, 8049, 8748, and 8749 devices.

Notable starting points:

* [`8048/8048.crd`](8048/8048.crd) — instruction-set quick reference, including 8039.
* [`8048/instr.txt`](8048/instr.txt) — architecture and instruction-set notes.
* [`8048/8048dis.zip`](8048/8048dis.zip) — a historical 8048-family disassembler, with C source and documentation.
* [`Eds8039Board/8039.htm`](Eds8039Board/8039.htm) — archived 8039 controller-board reference.

These tools are historical artifacts. Validate any generated listing against the ROM bytes and record the tool, version, options, and assumed CPU before treating it as analysis.
